# Χρονοδιάγραμμα αναρτήσεων

Αυτόνομη έκδοση για GitHub Pages.

## Ανέβασμα

Ανεβάστε ολόκληρο τον φάκελο `timeline` στο repository. Ο φάκελος πρέπει να
περιέχει και τα δύο αρχεία:

- `index.html`
- `fact-review-logo.webp`

Με ενεργοποιημένο το GitHub Pages, η σελίδα ανοίγει στη διαδρομή
`/timeline/`.

Το γράφημα περιλαμβάνει τους πλήρεις τίτλους και τους συνδέσμους των 12
δημοσιευμάτων. Το λογότυπο και η χρωματική παλέτα αντιστοιχούν στο γράφημα
ανάλυσης δικτύου.
